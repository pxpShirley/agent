双色纪律

冰青＝系统语言；暖金仅用于「人的环 / 需要你」，绝不污染。

层级深度

背景极光 → 玻璃面板 → 磨砂片 → 文字，四级清晰可辨。

动效节奏

统一缓动 cubic-bezier(.22,1,.36,1)，时长 0.2–0.34s，微交互可感不喧哗。

零浮层

所有反馈内联或同页区域切换，不弹窗打断阅读焦点。

已具备的能力

  • 多轮流式对话 + Markdown 渲染
  • 多智能体步骤流（planner/researcher/executor/critic 实时呈现）
  • 人在环确认（高风险动作前确认卡，4 段决策）
  • 结构化产物（行程/报告/清单/笔记，可编辑/导出 MD）
  • 记忆 / 提醒 / 心情（跨会话聚合，仪表盘可视化）
  • 主动服务卡（晨报/到期/周复盘/提醒）
  • 治理层（密钥/模型/运行设置）
  • 语音输入（SpeechRecognition + 波形）
  • 情绪调色板 + 星核伴生体形象
  • 能力网格 + 历史会话 + 主题（暗/亮/暖/精简）

缺口 / 半成品

  • 多模态输入缺失（仅语音，无图片/截图理解）
  • 语音单向（有输入无播报 TTS）
  • 产物仅导出 MD，无分享 / 可视排版
  • 主动洞察较薄（仅卡片，无「今日」聚合视图）
  • 无新手引导 / 个性化昵称
  • 能力网格为静态预设，未与真实工具/技能打通
建议落地的 1–2 项高价值能力（请确认）

① 多模态图片理解——上传/截图即可问（看菜单、看风景、看物品），是「AI 时代」最具辨识度的能力，生活助手高频场景。
② 语音播报 TTS——补全语音闭环，通勤 / 眼睛休息时朗读回复。
