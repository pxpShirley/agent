贯穿全局的关键约定

确认 UI 单一入口待确认时只有「人的环」浮层；对话内联的确认卡仅在已决策后留记录，禁止两份同现。
暖金只属于人暖金仅用于「人的环 / 待确认」；冰青代表系统语言，二者不可混用。
多轮上下文注入每轮把会话历史（上限约 12 条）注入模型消息，避免"每轮失忆"导致的反问与机械回复。
工具单一数据源提示词里的能力清单与实际下发的工具数组，同源于 tools/registry.ts，杜绝能力漂移。
结构化时间判定模型自由文本时间一律归一为 due_ts；解析不出即为空，绝不猜测，避免误触发到期提醒。
引擎看门狗前端 6s 无内容即中断流并回退本地兜底，防止上游配额耗尽时整会话静默卡死。
